## 🔹 Exercício 01: Par ou Ímpar (`ex01_par_impar.c`)
**Conceitos aprendidos:**
* **Operador Modulo (`%`):** Cálculo do resto da divisão por 2.
* **Estrutura Condicional (`if / else`):** Tomada de decisão para identificar se o resto é `0` (par) ou `1` (ímpar).
